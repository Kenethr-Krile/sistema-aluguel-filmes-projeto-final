# sistema-aluguel-filmes-projeto-final

SISTEMA DE ALUGUEL DE FILMES

Projeto final de lógica de programação do 1o semestre de desenvolvimento de sistemas pelo SENAI.

Professor: Victor Moak da Silva Souza
Turma: G104190

Critérios de Avaliação

/-------------------------------------------------------------/

Resultados comuns para todos os sistemas.


Contém uma interface clara e bem estruturada para o usuário.

As operações devem ser estruturadas em funções e/ou arquivos separados.

Menu iterativo que deve ficar em execução até que o usuário deseje encerrar o sistema.

Tratamento e validação de possíveis erros.

O projeto deve ser upado no GitHub.

Salvar e ler os dados corretamente em arquivos (1,0 ponto extra).

/-------------------------------------------------------------/

Sistema de aluguel de filme
GRUPO 01

Deve ser capaz de cadastrar filmes.

Deve ser capaz de remover filmes.

Deve ser capaz de listar filmes.

Deve ser capaz de Simular locação.

Deve ser capaz de cadastrar os clientes.

Deve ser capaz de listar os clientes.

Deve ser capaz de realizar login.

Deve ser capaz de cadastrar as locações através dos códigos dos filmes e dos clientes.

Deve ser capaz de buscar as locações por cliente.

Deve ser capaz de listar todas as locações.

Deve ser capaz de buscar as locações por filme.

Deve ser capaz de listar todas as locações por período, calculando o total de faturamento.
